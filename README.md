# Manifesto for Human Authorship in Technology

**Author:** Nicholas Daily  
**Date:** 03/30/2026

---

## Introduction

In today's world, we are entering a new age of development where we are using artificial intelligence tooling to generate code that will run in a production environment. We as developers and organizations bear a heavy responsibility to ensure the software we are providing is safe, reliable, efficient, and future-proof.

We hold the world in our hands; code that we ship to production environments has very real impacts for humanity. We are writing software for entertainment, storing sensitive information, maintaining life, human physical safety, security, etc.

There is a rising concern inside and outside of the tech industry over the use of artificial intelligence. However, this is an issue that transcends any tooling in the production of code. It applies not only to AI-generated code, but also to code we introduce through our dependencies, our Stack Overflow queries, our Google searches, and all the way down to the individual characters we type directly into the source code.

---

## We Value

- Code ownership
- Quality over convenience
- Developer autonomy over outsourcing
- Accountability over ignorance

---

## Our Commitment

Our commitment is to remain in control of the software we ship. There are different levels that we can adopt when we create software, but it all starts with human responsibility:

---

### Level 1 — Human Responsibility

- Code introduced must be understood by its author
- Code introduced behaves as expected within the system
- No "mystery code allowed"
- A human is accountable for every change

---

### Level 2 — Human Authorship

- Code is written directly by human contributors
- No generated code is committed

---

### Level 3 — Minimal External Trust

- Dependencies are intentionally limited and reviewed
- Prefer internal implementations

---

### Level 4 — Fully Self Reliant

- Core systems developed and maintained in-house
- Near-zero external dependencies
